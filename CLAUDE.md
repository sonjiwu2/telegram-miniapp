## Git Workflow

- После завершения любого логического блока работы всегда делай коммит.
- Используй команду /commit или обычный git commit.
- Сообщения коммитов пиши в стиле conventional commits (feat:, fix:, refactor:, chore:).
- Не добавляй Co-Authored-By и упоминания Claude.
- После коммита сразу пушь изменения на origin.
- Работай только в текущей ветке, не создавай новые ветки без спроса.
